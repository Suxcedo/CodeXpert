Introduction to Websites and Web Development

Before building websites, let's understand what they are, how their pages fit together, and where CodeXperts fits in.

By the end of this lesson, you'll be able to:

✓ Explain what a website is.
✓ Describe what a webpage is.
✓ Identify the difference between a website and a webpage.
01

LET'S START WITH THE BASICS

1.1.1 What is a website?

A website is a collection of related webpages that people can access through a web browser, usually using an internet connection.

A website may provide information, display pictures, publish news, sell products, teach learners, or allow people to communicate.

🎓

Think of a university website

A university website might contain several pages:

  • A home page introducing the university.
  • An admissions page explaining how to apply.
  • A courses page listing available qualifications.
  • A contact page containing contact details.
🧠
Remember this

A website brings related pages together under one online home.

02

NOW, LOOK CLOSER

What is a webpage?

A webpage is a single page within a website.

Think of a website as a book and each webpage as one page in that book. The pages may contain text, images, videos, links, forms, and other content.

📚 Website The whole book
→
📄 Webpage One page in the book
